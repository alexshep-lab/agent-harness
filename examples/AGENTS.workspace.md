## 1. Как агенту работать в этом пространстве

1. **Начни с этого файла**, затем — с профильного `AGENTS.md`/`README.md`
   нужной сферы, затем — с конкретных файлов.
2. **Задачи всегда через Todoist MCP**, а не через выдумывание из головы.
   Не дублируй задачи в markdown.
3. **Правило стоппера.** Пользователь перегружен. Прежде чем предлагать «ещё
   сделать», оцени: не вытесняет ли это что-то важное. Честно называй
   перегрузку. Не гони новые фронты.
4. **Не реорганизуй файлы в день реальной работы.** Уборка — отдельный режим.
   Не перемещай и не удаляй файлы без явной просьбы. Создавать новые
   контекст-файлы (README/AGENTS) — можно.
5. **Язык и стиль.** Рабочий контент — русский; технические термины —
   английские. Тон: прямой, конкретный.
6. **Границы контекста.** Один проект = одна папка = один самодостаточный
   контекст. Не смешивай.

## 2. Карта рабочего пространства (сферы → папки)

Структура — PARA с числовыми префиксами (алфавитная сортировка ставит
системное наверх).

```
00_Система\        ← правила, шаблоны, индексы, приоритеты, летопись. Мозг системы.
10_<Research>\     ← научная сфера (диссертация), консолидирована в одной папке
20_Продукты\       ← собственные продукты (каждый — своя подпапка, код на отдельных дисках)
30_Инженерия\      ← НИОКР-программа (активные проекты в _Активное\)
40_Личное\         ← рутины, документы, финансы
90_Входящее\       ← буфер для неразобранного (разбирается до нуля еженедельно)
99_Архив\          ← межсферный архив, чистка раз в полгода
```

**Ключевые системные файлы (`00_Система/`):** конституция
(`Правила_и_стратегия.md`), живой индекс активного (`Индекс_проектов.md`,
WIP-лимит 5–6), приоритеты по горизонтам (квартал/месяц/неделя), хронология
(`Летопись_система.md`), шаблоны AGENTS/README.

## 4. Ресурсы

- **Файлы:** эта папка; код продуктов — в отдельных рабочих директориях на
  других дисках (в каждой — свой `AGENTS.md`/`CLAUDE.md`).
- **Todoist через MCP:** обзоры (`get-overview`), поиск задач, создание;
  **перенос даты — только `reschedule-tasks`** (сохраняет recurrence).
  Модель: **capture** (мессенджер) → **processing** (Todoist, 1×/день, здесь
  помогает агент) → архив.
- **Внешние AI:** каждая папка проекта задумана «скармливаемой» стороннему AI
  без пояснений. Если контекст несамодостаточен — это дефект AGENTS/README,
  который стоит починить.
